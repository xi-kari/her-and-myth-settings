# 《她与神话》设定总览

本页整理设定原文及作者明确方向，不新增故事事实，不把助手工作案变为作者定案。原始00—05与历史各版均保留；具体来源效力见[来源与效力](来源与效力.md)，未接问题见[待定与冲突](待定与冲突.md)。被作者撤回的新正篇001—050和旧001—070没有进入本页的事实依据。

## 故事要讲什么

《她与神话》是黎见曦与盛世澜的双女主百合星海幻想长篇。两人的爱情、远行、专业、朋友与独立选择共同支撑故事。她们经历不同的世界，形成有价值又有局限的答案，并亲自参与彼此成功所必需的行动。

A的黎从爱人和故乡的具体遭遇出发，看见神性支配能够如何伤人，也看见人的创造、过错、互助和生活。她最后取得诸神全部已成立概念，把“神爱世人”写进神格与生命的关系，再重启生成B。

B的盛从真实受到保护的生活出发。这个世界确实比A有改善，教育、照护、远航和改革都有真实成果。她继续发现：神真心关切人，仍可能理解错、害怕失去、拒绝人离开，并保留对人生的最终决定。她及同行者因此继续争取人的未来，终止完整神格及其再生条件，向前进入C。

A的神爱是当时实际争取到的成果；B的去神需要在这份成果上继续前进。不能让B证明黎从头到尾都做错了，也不能把无神写成此后人人正确的完美世界。

## A、B、C与两条个人经历

| 层面 | 含义 |
|---|---|
| 世界谱系 | A真实存在，A终幕先写法、再重启生成B；B去神后继续成为C。不是三个永久并行的社会。 |
| A叙述 | 主要随黎，常规奇数正篇；她当时只拥有已经亲历、实际取得的知识和力量。 |
| B叙述 | 主要随盛，常规偶数正篇；B有自身的出生、社会、历史和成长，不照抄A生活后集体失忆。 |
| 暂访的A黎 | 尚在较早个人阶段，携自己出发时已有身体、能力和物件进入B，完成行动后返回A。 |
| 常住的普通B黎 | 已亲历A及写法重启，保存实际记忆、失去神格权能；本人可见、可触、能工作和重新相爱。她不是永久欠着返程的访客。 |
| 成熟B盛返回A | 盛在较晚人生阶段真正抵达A，承担实际行动、伤耗与返回，不是投影、旧录音或幻象。 |
| C | B向前的真实无神未来；两人仍是本人、拥有有限身体，可以旅行、安家、工作、衰老和相爱。 |

两位主角各只有一条连续的个人生命。同一人较早与较晚阶段可以同场，但不共享心声或自动同步记忆，不用年轻者昏睡、借体或复制另一人让位。

A/B交错是阅读顺序，不表示同一日期或同一地点。内部正篇节号常规奇A偶B，序章和外篇独立编号；一本书可以同时包含两线。两线的地方历史有差异，不要求复制同一场事件、同一段灾难或同一条路线。

必须保留双向必要的本人帮助：B盛实际到A帮助黎，A时期黎实际到B帮助盛；至少各有一项行动对当时成功不可缺。知识应分别来自A的研究与取得、B的生活与试错，不让全部答案只在循环中互抄。没有一遍原本独自成功的A，再把来客补成奖励。

具体哪两次帮助、哪些高潮、停留多久属于需要重新安排的实现。四访、九访、每星一对等历史排法不等于宇宙必须发生的次数。

## 离乡、寻找与返乡

作者当前明确的前中段结构是：A黎与B盛各自踏上星际旅程，经过一段行旅后进入异星；让她们分别遇人、学习、行动，形成相似与不同。前中期不安排普通返乡团聚，较后阶段回故乡直面神明；时空交错是少数有分量的重要事件。双主角父母按作者意图避写，不主动展开。

独行指各自承担自己的旅程，不取消船员、朋友、老师、地方人与普通交往，也不把整个前中段写成孤独受苦。两条线的呼应可以由不同选择、不同历史后果和意象形成，不需要立刻让两人在同一房间解释关系。

A的原始动机是想救盛、理解故乡发生的事。她逐渐发现一个人的遭遇连着更广泛的神与人的关系，才走向更大的行动。晚返乡在04 V23—V27仍有明确骨架：先在外部学会本领、取得真实来源，后来再面对故乡的人、实验、救援和第一神。

P011明确保留“盛不再献祭—黎的缺失—盛寻找黎”的B情感来路。P012澄清黎不是肉身消失、仍能重新认识、追求与共同旅行；这并没有指定她开篇就在盛身边，也没有规定第一卷必须确恋。普通B黎何时进入盛的旅程、先发现何种空缺、怎样真正重识，须在作者要求的独行结构中重新梳理。

原04的第一异星工作安排为A砚泉、B澄海及白汀外泊；它是有详细资料支撑的路线候选，不是已经发生的事实。原三十阶段、具体章号、恋情窗口与旅程日数都不能代替人物行动的因果。

来源：[P011寻找黎](02_设定补丁总集_P001-P016.md#p011)、[P012普通黎](02_设定补丁总集_P001-P016.md#archive-p012)、[04 V02](04_全书叙事总设计_长序章_AB_C与异闻.md#v02)、[04 V23](04_全书叙事总设计_长序章_AB_C与异闻.md#v23)。作者本轮关于独行、晚归和少数交错的说明优先于冲突的工作排法。

## 两位主角

### 黎见曦

女性，起初偏历史、记录与研究方向。温和、细致、敏感、执拗，喜欢追问出处与被略去的细节。她想让重要的人被认真对待，也希望自己的判断与投入有分量。

她会高估一个细节，想把事情全部问清，在亲近的人面前也可能把一次失约追成对动机的判断。她不能永远正确、永远牺牲或只做记录员。随着能力增长，她的危险倾向是相信更完善的规则可以替所有人排除伤害，进而压缩别人改变想法的空间。

人物底稿给她通俗冒险、图册、对角色护短、熟人面前多话和逗人的一面。她会想被偏爱，也会主动索取、害羞、发脾气、接受照顾。普通B阶段的价值来自真实知识、劳动、身体、判断和关系，不能靠暗藏神位保证重要。

### 盛世澜

女性，起初偏航行、空间定位与实际操作方向。松弛、温和、可靠，有远行欲望和好奇心，也会偷懒、迟到、忘收东西。日常随意与专业认真可以同时存在。

她希望被视作能共同承担的人。她会答应过快、低估小事相加的时间，想用玩笑或新承诺赶快修复别人失望，反而没有听完。她也能恼、害怕、求助和拒绝，不是专门负责保护与开导黎的人。

人物底稿给她拆修小器具、喜欢声响、小调和陌生路线等趣味。B中回返经验增加后，她可能把“我知道曾经失败”误用成“我可以替别人安排”。成长要让她真实尊重其他人的判断与选择，而非只变得更沉重。

### 爱情与记忆

A序章两人青梅相伴、已经交往不久。B盛起初不认识黎，渐进恢复的是她自己的A亲历；黎独行的事、没说出口的心思不能自动被她想起来。旧关系不替当下双方答应爱情。

她们可以因为专业、兴致、脾气、偏心和身体吸引而相爱；相处有笑、欲望、争执、笨拙、安静和实际改变。亲密不需要每次产出线索或道理，也不能只承担创伤后的治疗功能。

约22岁是工作年龄，准确生日与部分学制仍须核对。太刀和花嫁戒的武器差异不规定恋爱中的强弱、主从或照护分工。

## 永恒与序章出发点

永恒采用尖端科技与神力应用并存的叠层文明。生活空间、天气、建筑审美可以不同，但身体和物件真实移动，不是全星模拟或梦境。古典楼阁、青春制服与先进公共技术能够同场。

学校和远航教育有真实知识与能力，船也有真实离星能力；少数受控流程被接入耗损实验，不等于全校、所有亲友和全部美好日常都是骗局。

现行主线构想是同一个轮回锚点承受多轮复原，相关耗损累积；锚点耗尽死亡后，实验阶段前移、另找承担者。盛属于多位承担者之一，适配性不是不会被耗尽，也不等于可以自主控制完整权能。普通被复原状态与承担复原的生命耗损须分开。

第一神诞生于永恒、关联永恒/轮回/命运为有效方向；文明意志成神是倾向。其具体人格、AI或集合体解释、姓名和旧晏持衡履历、统一神史尚未完成。固定六年、Y-742、r123/s4和开局两年期限均不能恢复。

保留的序078—080实际写盛在持续医疗支持中真实死亡、遗体被内台留置、黎独自离域并求援。它没有写后来已获救、已返乡或B复生。旧前置活体旁路与现行真死不兼容，不用它悄悄把失去改成假死。

2026-10-28 作者指出：永恒写成了古风，可他要的是“时空交错穿梭”的叠层星球。现在的写法：迈过接合就换一种天，床头的选层屏决定醒来窗外是哪一层，远处永远是望昼塔和云海，校服是领结和褶裙；古风只在荷照旧苑。日常的样子见[永恒星：叠层日常](世界/永恒星_叠层日常.md)，序卷世界层修订版已照此改。

同名A/B神、普通人或地方机构不自动具有同一主体、同一记忆与同一命运；双主角的连续本人要求不能批量套给所有人。

星海也有自己的社会：白汀外泊、迁行船群、空间船坞、远测站、教学船、无神星港。船群的路线可以是故乡；外泊居民有学校与日常；无神星港有普通供水、农业、工坊和共同防卫，不是没有社会代价的自由天堂。

航程需要船、船员、护息、补给、航窗和对端接待。技术可以传播，但需要材料、训练、维修和当地适配；不能所有地方只换名字使用同一种现代工业，也不能为保持地方风格强行禁止交流。

十星是重点建设样本，不是宇宙总数；一颗星不必只配一个主题、一位神、一场战斗。主段结果可以是护撤、工程、演出、一季生活或一次真正完成的改革。

## 神、能力与战斗

自然时间、空间、生命、灵潮先于神。普通人通过学习、器物、咒文和工艺可以施展有限术法。神格让一个主体对概念的判断能够成为持续施行的规则，不等于全知全能。

必须分清概念类型、具体完整核心、人格、地方本位、施行路径、有限份额和神器。取得核不赠送前神全部人生，也不等于马上掌握全部用法；同型概念可能有不同来源的独立核心。

作者已确认黎持太刀、盛以花嫁戒指施法。照夜、白誓的名字、传说、取得故事和具体招法是现有工作基础，未被逐项冻结。黎应有接近、判断刀路、落刀与承受反击的本领；盛应有铺开、控制、追击、保护与直接攻击的本领。两人都必须学习，不以悲伤或器物自动换来成熟战力。

后续作者已确认时间、空间、永恒、轮回、命运五核真实传给盛：先由A黎真实取得，再在终幕真实交付。普通B黎无核。这五种不是A最终所得的全部概念；二十种具名A类型也不是宇宙总数。核的来路、传承、封存、分期适配、可用程度和消耗仍需分别成立。

真实战斗依对象、位置、连接、供能、规模、精度、注意和对手反制发生。不能用概念名称大小判胜负。地方合作、普通装备、救护与撤离也能不可替代。

神死、退位、交核、去神和还人不同。可以还人成活、还人后因伤病与岁月死亡，也可以在冲突中真正终止人格；不要求每颗星都杀一位神。地方公共生活的接续同样是结果的一部分。

## 时间、归岸与本人复生

| 操作 | 不能混淆的含义 |
|---|---|
| 永恒本地实验 | 在真实绑定的本地范围复原，锚点承担累积耗损；外部星海继续前进。 |
| A写法与重启 | 先改变神格规则，再重展B；不是普通回档到较早的A日期。 |
| B归岸 | 在B实际当下预先建立有限返路，返回有效锚点；短战与长旅使用同一有限原则。 |
| 跨版本访程 | 本人携身体、当时能力与物件抵达另一版本时位，实际行动并返回。 |
| 普通B共同生活 | 黎已完成A重启后的正常生活，不因此永久停用B归岸。 |

归岸工作体系中，一次只有一个有效锚，返幅与余力须事前建立。锚后的物件、核心归属、神死、还人进程与新关系一起回退；不能只撤销损失、保留战果。保留下来的亲历和不可退回耗损不能用同次回退清零。敌人默认恢复锚时记忆，真实独立保留须另有来源。

跨版交付未闭合时，B不能单方面回返删掉已经成为A来源的事实。不同个人时龄的同源核可暂时同场，不能积成永久双份库存。身体年龄、清醒经历、外部历时和反复亲历分开，不把多年记忆直接等同于身体老去，也不让无核者默认不老。

作者已允许沿人物或旧物的前史回溯，并允许实际条件支持时重排更早营救。不能以“目标当时没预建一座端”、命运或同源排斥一概挡住，也不能据此推出无限时位、载量与返程。

盛的现行A真死与B同一本人必须接到真实的身体、生命和经历来路。甲案“重启中接回”、乙案“A后期原躯先复生”都没有被单独采用；旧活体旁路已不能代替真死。允许早救以后，需要认真检查能力与死亡事件的相容，不能一边声称救成、一边保留所有只由死亡产生的后果。

这些未接实现须在使用前解决，但本次不拿一串远期选择题替代设定梳理。

## C、史传、番外与寓言

C继续真实普通生活，有各自事业、旅行、租屋、朋友、身体吸引、生活麻烦与变老。自然术法和科技继续；完整神格、再生条件、私人归岸、永久跨版门和不老权能不作为秘密后手留下。

史传让前人有自己的希望、事业、责任、日常和后果，不只是留一张纸然后死去的线索工具。主线必须使用的关键知识仍要由当代人物实际取得，不能藏成读者可跳过的唯一解。

寓言应从当地市井、历史、行旅或星际见闻生长，对正文有具体解读或预示；旧动物器物童话是候选素材，不默认全部采用。文学预示不等于真实预知、复生证明或通路。普通生活细节也不必全部成为以后回收的伏笔。

C与外篇可先给读者未来信息，但不自动让早期人物知道。具体插读位置须按新结构规划，不沿用废案020之后等位置。

## 语言与阅读感受

正文的中心是人物此刻想做什么、怎样遇见别人和世界。专业要改变行动，但不逐页展示档案核验、付款、受理和边界确认。后台的因果严密服务于前台的惊异、美感、情感与欲望。

清楚的现代中文可以有长句、直接心理与浪漫，不把去模板变成全篇碎句。普通日子可以完整展开；配角也可以在主角不在场时拥有自己的故事。主题由选择与后果累积，不让每人轮流说结论。

作者关于流星夜重新认识、故事将尽时回想开头的希望，已有现行序章中的姓名、伸手、阅读开头与望昼塔作为基础。未来回扣要让那一次相遇有新的经历，不能把意象直接当作时空机制。
