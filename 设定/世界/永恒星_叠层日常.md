# 永恒星：叠层日常

状态：工作方案（2026-10-28）。作者已定的方向来自 P010、P011、P012 和 01 号设定的永恒部分；序卷里已经写出来的地方标“序卷已有”，新提出的标“新”。作者看过可以随时改，改过的以作者为准。

## 先看这一段

永恒是一颗被叠起来的星球。同一块地方同时有好几种样子：这一步还在晴天的课楼前，下一步已经走进落雨的步道；睡前窗外是荷塘，醒来同一扇窗外是云上的楼阁，床头那杯没喝完的水还在原处。

这里的人从小这样过日子，跟我们坐电梯一样平常。科技是最先进的，日子是现代的：上学、通勤、发消息、约会、挑衣服。校服是领结和褶裙。远处永远立着望昼塔，塔下是云海。古典的楼阁和荷塘，只是其中一种风景。

作者给过的感觉参考：《泰坦陨落2》里同一处地方在两个时间之间来回切换；《星之终途》里高耸的中心建筑、层层叠起的巨城、冷色的远景，一个女孩站在巨大的结构前面。

## 一、叠层是什么感觉

**每一层都是真的。** 同一个位置叠着几种环境：不同的天气、季节、时刻、建筑外观。每一层都是建好、有人维护、大家共用的地方，不是幻象，也不是屏幕。

**换层就是迈一步。** 公共的连接段地上有一道很细的光，叫接合，走过去就换了。过接合的那一下：耳朵轻轻一胀；气味和温度先变，雨的土腥、荷叶的青气、高处的冷；光的颜色晚半拍才跟上。手里的杯子不会洒，下一步已经听见另一场雨。

**能隔着看。** 接合处常留着一扇“窗”，看得见隔壁那一层。序001 开头，接合那边在下雨，雨落在长长的顶棚上，离黎只有一步，云庭这一层却晴着（序卷已有）。

**交通工具也穿层。** 接驳车经过接合，窗外亮一阵，光沿着车身滑过去，再看窗外，已经铺开一大片荷叶（序007，序卷已有）。

**屋里可以换景。** 在场的人都同意，就能把一面墙或一扇窗外的环境换掉，桌上的东西不用挪。序007 的手作展，塘边换成了正在下雨的山廊，桌角那杯茶还冒着热气（序卷已有）。

**普通人看标识，适应强的人凭感觉。** 大家用终端选层，跟着地上的指引走。适应时空的人不看标识也找得到接合。

**不变的东西。** 身体、手里拿的、随身带的、固定的家具。人不会因为换层变成两个；同屋的人看见的是同一个变化。

## 二、一天怎么过

**醒来。** 床头有一块小屏，睡前选好“醒来的那一层”。人还在自己床上，窗外从荷塘换成了云上的楼阁（作者原意象）。黎喜欢荷塘下小雨的早晨；盛喜欢太阳从云底下升上来。两个人住在一起，醒来那一层要商量，跟挑闹钟铃声差不多（新）。

**穿衣。** 衣服用适配的料子做。云庭的校服是水手领、领结、褶裙、短外套（作者：JK最好看）。走进荷照旧苑，同一身校服会顺着折线变成旗袍或古衣的样子，颜色和校徽不变；走进远汀的训练层，它会变硬，成了轻甲和航行服。喜欢的那件可以“锁装”，跨层也不变。发夹、手环、戒指这些私人小东西从来不跟着变。序007 里那个女孩一抬手，披帛就顺着折好的线扣到肩上（序卷已有）。

**上学。** 从住区到课楼要过两三道接合，走路十几分钟，比坐车快。早课前连接段排着队，推车的住户和拎早餐的学生挤在一起（序001，序卷已有）。

**上课。** 光页摊在桌上，终端放在桌角，送物匣一格格停在窗口，有人取走，空匣子顺着外沿滑回去（序001，序卷已有）。

**午饭。** 课楼的天台接在云上那一层。午休的时候学生在云海上吃饭，风大，饭盒盖要压住。有人在栏边回头叫人，长发被风吹起来（新，作者想要的“天台回眸”）。

**放学。** 接驳车、去望昼塔的专线、澄镜水园的夜间观景车。

**夜里。** 生活层的天大多调过：亮、干净，星星少；只有云上那一层是真的夜空，看得见流星（新）。望昼塔东侧外环入夜会把遮光灯调暗（序011已有）。写夜景要写清这是哪一层的天。

## 三、地方

| 地方 | 看上去是什么样 | 序卷里的落点 |
|---|---|---|
| 云庭学住区 | 白色的退台楼群托在看不见的结构上，像几片错开的叶子，连接段从叶片之间伸出去，在下一个端口消失（序007已有）。课楼外墙爬着学生养的花墙，窄轨从花间穿过。课楼本身有晴层、雨季常开的雨层，天台在云上层。 | 第1–2篇日常 |
| 空中楼阁（新落点） | 云庭住区的一种居住层：楼阁悬在云海上，光桥连着，窗外是翻滚的云。想住哪一层，跟租房一样挑。 | 住处、留宿、第5篇 |
| 澄镜水园 | 真水、栈道、夜间观景车，水陆两族各有入口。水族馆的同一面玻璃后面叠着几层水：上午是阳光照透的浅海，傍晚换成会发光的深水。有一种小鱼会自己穿层，游到一半不见了，过一会儿从另一面玻璃里游出来，孩子们叫它“换层鱼”（新）。 | 第2–3篇约会 |
| 层轮（新） | 水园边上的摩天轮。车厢转一圈要穿过几层：底下是下午的水园，半腰在下雨，最顶上那一分钟转进云上层的夜里，看得见星星，运气好能看见流星。 | 第3篇约会 |
| 荷照旧苑 | 古典楼阁、荷塘、白墙、挑檐和檐角小灯，剧社和手作展常在这里办，用的是一样的先进设施（序007已有）。古风只在这里当一种风景。 | 第1、4篇 |
| 远汀航学区 | 远航学校：训练楼、模拟舱、实训泊位、投在地上的停泊线、不能越过的白线（序卷已有）。星帆船停在泊位上，银色的帆折着，像收起翅膀的蛾子（新）。保障区另外管着。 | 第4–6篇 |
| 望昼塔 | 少数每一层都看得见的东西，大家拿它认方向。升行车沿塔身往上，每上一段窗外换一种天：晨光、正午、雨、黄昏，最后冲出云海（新）。观景层的外环在云海上面。作者最喜欢的画面在这里：高塔、云海、回头的女孩。 | 序011、序057 |
| 叠灯节（新） | 一年一夜，所有层一起打开。几层天叠在同一片夜里，每一层的灯都浮在一起，街道看起来有好几重，走着走着会跟别的层的人擦肩。 | 序034—035的灯市，或回云庭另写 |
| 只有一层的地方（新） | 永恒也有没叠层的原生地带：海岸、礁石、老树、真正的季节。住惯叠层的人到了这里会不习惯：只有一个天，下雨就是下雨。 | 第3篇石铃岬、老树（南堤看原文再定） |

“只有一层的地方”是给全书结尾埋的根。叠层落下以后，剩下的就是这颗真正的星球；黎和盛在这里第一次觉得，世界只有一个样子，也很好。

## 四、东西

终端、记录器、轻屏、光页、送物匣、音匣、入塔凭条、遮阳叶、升行车、接驳车、观景车、床头选层屏（新）、适配衣装和锁装（新）。都是平常东西，写人怎么用、嫌它什么，不写原理。

## 五、神在日常里

公共告示上，神力接续的示意图旁边写着“永恒之神”，底下是维护班次（序007，序卷已有）。人们感谢祂、依赖祂，就像感谢供水供电。

有些层是靠神力撑着的，往往是最高、最美的那些：空中楼阁、云上的夜空、塔顶。全书最后它们会落下来（见第七节）。

老人们有句玩笑话：“哪天层要是掉下来，天上能下一整夜的流星。”序卷里只提一次，当闲话或者哄小孩的话（新）。

## 六、时空交错

作者已定：两个人都适应时空，一个偏时间、一个偏空间，目前的倾向是黎偏时间、盛偏空间；每一轮轮回都会让她们更敏感，某一次突破让黎察觉了献祭（P011、P012）。

**黎会“看重”。** 有时她眼前的地方会叠上它不久以前的样子，很淡，像曝光了两次的照片：刚拆掉的旧栏杆、几分钟前走过去的人。她从小就有，以为是眼睛累。别人看不见。

**盛不会迷路。** 她不用看标识就知道接合在哪儿，跨层从不走错，有时还能找到没标出来的接合。上了船，她比仪器先感觉到接合。

**序卷里怎么用：**

- 平时只给零星几下，不解释。
- 黎看重（序卷已有）：序003 泊位上一艘已经开走的船；序042 老树上那根早断了的枝；序057 东侧外环两个很淡的人影，站在她们上次站的位置，她没说；序065 公二升台旁的停留位上多出一只旧舱，舱门开着，门边站着几个人。
- 盛找接合（序卷已有）：序003 灯还没亮她先知道；序007 荷照里没标出来的接合；序045 比记录面先感到泊接接通；序062 见远上耳朵先胀，后来才查出那道回折；序070 邻居说她小时候坚持送物车“在等它认得的那一层换回来”；序071 见远穿过护接面，她觉得跟在家里迈过接合一模一样；序072 一道接一道被往里领。
- 第6篇的突破（序卷已有，序076）：黎走到检修桥中间，看重全开，像《泰坦陨落2》那样来回切：内台翻出前几轮，同一张架子上躺着盛，旁边没有人；弧面里翻出前一轮的教学泊位，盛登船回头挥手，公众段后面有个人用黎自己的手势回挥，穿着一件黎没有的外衣。后来盛问她看见了什么，黎说“每一回，旁边都没有人”，盛说“这回有”。挥手的那个人留着（作者 2026-10-28 定）。

**规矩，只有三条：** 看重只能看，碰不到；真要跨时间做事，得等A线她后来有了力量；时空交错不白送答案，也不拿来随便穿越。

## 七、给三段流星埋的种子

作者选定“流星重逢”用三段场景演出来，不让人物念台词：

1. **坠星**：白汀外泊（澄海的月旁）外圈一段老泊环脱落，碎片在澄海的天上连烧几夜，其中一颗流星是盛的船（2026-10-28 定，详见[星海与航行](星海与航行.md)）。黎朝它落下的方向跑过去，把人拉出来。盛问“你是谁”，黎报上名字，像第一次见面。这一段和序080反过来：那时是黎在小艇里求救。
2. **两个夜晚**：盛找回记忆的那一刻时空交错，序011望昼塔的那个夜晚叠到眼前。过去的两个人许约，现在的两个人守约，一颗流星同时划过两个夜晚。
3. **层落之夜**：回到永恒打破轮回，神力撑着的那些层脱落下来，烧成满天流星。星球没有毁，回到了本来的样子。还是那座望昼塔：序011她们等了一晚上只看见一颗，这回满天都是。盛在云海上的塔顶回头。

序卷里已经埋下的种子：序011 原来的约定，和老人那句层落的闲话；序036 层轮转到云上那一层，黎找了一圈，没看见流星；序040、序041 只有一层的地方，“这里的天只有这一个”；序057 黎看重；序070 盛临走把自己屋里的窗定在云上那一层的夜里；序080 黎第一次从星外看永恒，弧外贴着几道很淡的边，像同一颗星被描了好几遍，她也想起盛那扇窗还停在云上的夜里。

首尾句按作者选的方案：“每当故事结束的时候，我们总会想起它的开始。”印在《北岸的第三盏灯》新卷最后一章前面（序008）；序080 黎想起那一页；全书最后一句由叙述说出这句话。

## 八、写法

1. 永恒的每一章至少有一处让人感到叠层：一次换层、一扇换了景的窗、一件自己变了样的衣服。写感觉，不写原理。
2. 建筑默认不是廊、檐、庭、院，是白色的退台楼群、玻璃、光桥、悬空的步道、错开的平台。古典外观只出现在荷照旧苑，或者人物特意挑它的时候。
3. 当地人不对叠层惊叹。惊叹留给孩子、外来的人，和黎看重的时候。
4. 夜里写清是哪一层的天；远处可以写望昼塔和云海。
5. 校服是领结、褶裙、短外套，跨层会变，锁装的不变。
6. 确认、核对、受理这些冷词，留给第5–6篇的流程和真相。
