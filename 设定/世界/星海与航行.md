# 星海与航行

状态：工作方案（2026-10-28）。依据是 01 号设定里的星海往来（星潮、各星借路的办法、航程表、护息）和 03 号十星总集第 11 分册（航路组、行星外的居所）。旧设定写过的标“已有”，这次补的标“新”。作者改过的以作者为准。

## 先看这一段

星海是大的。十颗星分在不同的恒星系里，船要走几天到几周，到了还得候潮、补帆、等窗口（已有）。可它也是走得通的：有人随船打工去求学，有人在船上出生，有人一辈子在接泊居所修船（已有）。

作者想要“时空交错穿梭”的感觉。放到星海里，落在三件事上：

1. **每一次过渡，身体都有感觉。** 永恒的接合是耳朵一胀；镜舟是先看见自己的倒影到了那边；星帆是水珠往上落。
2. **渡口能看见别处。** 星潮开口的地方，隔着潮光能看见对岸的港，甚至看见人影。可航图写的是来向和潮况，看见一个人的影子，不等于能开到她身边（已有）。
3. **时间会错开。** 在航日数不等于从房门到房门；各星的年、季、窗口长短都不一样（已有）。两个人分头走不同的路，再见时，各自过了不一样长的日子。

## 一、星潮

星潮在神出现以前就有了，没有意志，也不替谁保证出口（已有）。

看得见的样子（新）：星海里一条一条很淡的流光，有宽有窄，平时只有老航手认得出来。开口的时候会亮，像海面上的一层反光。顺着它走省力，逆着走慢，走错了可能回不来。候潮，就是等它在两头都开。

## 二、各家怎么借路

凡人用镜舟、星帆、引潮木、护息纹和不同的传授借路；有人自己试出办法，有人跟外来者学，也有人被殖居者控制了渡口和师承（已有）。

| 星 | 办法 | 穿梭那一下（新） |
|---|---|---|
| 永恒 | 本地浮舟接上外来的星潮知识（已有）。当代 A 线没有常规班次（已有）。日常靠接合与接续。 | 迈过接合：耳朵一胀，气味先到，光晚半拍。 |
| 衡川 | 镜舟，从水镜、河工和炼金里试出来（已有）。 | 船头扎进水镜，先看见自己的倒影到了对岸，身子晚一步才过去。 |
| 丰原 | 外来帆艺接上古桑枝渡和本地树脂（已有）。 | 枝梢的叶子一齐朝天上翻过去，船顺着翻过去的那一面离开。 |
| 澄海 | 海星兼航的星帆（已有）。 | 海平线亮起一条比海还亮的线，帆纹一格格亮，船底离水，水珠往上落。 |
| 砚泉 | 借潮古辞，一年两段接舟季（已有）。 | 修士在露台上念辞，彩窗的颜色一块块熄掉，只剩一条路那么宽的光。 |
| 燧庭 | 自己造的船，跨谷轨道助跑（新）。 | 轨道的响声停下的那一瞬，船已经在潮里了。 |
| 赤旌 | 空艇，加上一部分外来船型（新）。 | 风从高原上把船托起来，峡谷一下子变成地图上的线。 |
| 鸣珀 | 外泊用接触媒介和光信号（已有）。 | 船落地，整片矿质林响一下；进了真空，只剩手底下的震动。 |

绮梦和霜灯多搭别人的船，有自己的港。

不同的船要真正兼容入口、护息和载量，镜舟、澄海星帆、砚泉星舟的载量不能互相冒充（已有）。

## 三、渡口：看得见别处的地方

渡口是星潮开口的地方，也是这个世界最“时空交错”的地方。

- **隔着潮光看对岸**（已有的基础上补）：对岸的港像隔着一层晃动的水，灯、船桅、人影都在，近得像能喊一声。喊了也听不见。
- **潮影**（新，2026-10-28 定用）：同一个泊位上，有时会多出一层上一班船还停着的样子，很淡，一眨眼就没了。老航手管这叫潮影，不当真，也不完全不当真。大多数人一辈子没见过，见过的也说不清。
- **和黎的“看重”**（新，2026-10-28 定）：黎在序卷里看见过地方的过去（序003、序042、序057、序065），序076 在内台上全开。渡口是她的看重最容易冒出来的地方：别人一辈子见不着一回的潮影，她看得清清楚楚，也更难收住。对别人来说，潮影还是航海人的传说。
- **规矩**（已有）：两端各有窗口，往返要分别约好；单方好天气，不能证明对岸愿意接船。神赐的捷径能缩短某一段，可一旦失效，不能还按旧航图赶路。

## 四、船上的日子

- **窗只有一层。** 船上的窗外是什么就是什么（序059 已有）。永恒来的人头几天醒来，会下意识去摸床头的选层屏（新）。
- **护息。** 护息纹让有限的空间能活人，要完整的纹路、合用的材料和清醒的守术人；会变弱，会破，替代不了饭、补帆和真正的照护（已有）。舱壁上的纹路暗了，就得有人去补（新）。
- **吃。** 返程的食水、补帆的料都要备齐（已有）。出港后的第一顿饭，通常是在码头上买的；到港前最后一顿，是把剩下的都煮了（新）。
- **不是每一程都出事。** 成熟班线可以顺顺利利地走；每段都安排风暴或劫掠，船员就没法正常谋生（已有）。平平安安抵达，本身就可以是让人高兴的结果。
- **钱。** 普通人靠随船干活、师门资助、家人合资或一起凑粮出行，不能无限吃免费的船饭（已有）。

## 五、行星外的家（已有，03 号第 11 分册）

- **白汀外泊**：澄海的月旁边。护息范围里长大的孩子，熟悉真空，不熟悉深水。观景窗要按强光的方向遮，看得见澄海的昼夜分界，听不见浪。
- **迁行船群**：几条家船、学校船、维修船按会合点相接，路线就是家乡。会合时办喜事、换学徒、分船。
- **空间船坞**：住、加工、外作业和储料分开。有人在这儿造一艘属于自己的船。
- **远测站**：有具体的观测目标和补给，一季没结果，工作也不算白做。
- **无神星港**：岐渡旧支路上，人工合泊和可居星屿连起来的混居地。要付宿钱、排队、问路。
- **教学船**：把研究、学习和真航行连起来，一学期以后，各人去各人的地方。

## 七、永恒为什么像被关起来

- A 当代没有常规班次（已有）。永恒的人知道“远航”，学校开远航课，见远是训练船。
- 序卷揭开的事：见远的“离星”一直在本地接续里打转（序060—序072）。J17 那条“外部首站确认接收”，来源是北侧分域内接第三区，本地生成。
- 见远上有真的外航设备，最后一次用来给短汀六撑开临时外护，黎才第一次真正到了星外（序077—序079）。
- 从外面看，永恒是一道很宽的弧，云往远处铺，底下一层层暗。看久了，弧外还贴着几道淡边，像同一颗星被描了好几遍（序079—序080）。这几道边是什么，正篇再定：可能是叠层从外面露出来的样子，也可能是前几轮留下的痕迹（新，待定）。

## 八、给三段流星的天象

承接作者 2026-10-28 选的“三段连用”（新）：

1. **坠星重逢。** 某处星港、外泊或一颗小月碎了，碎片成了一场流星雨，盛的船是其中一颗。黎跑去救她。盛问“你是谁”，黎报出自己的名字——和序080 黎对着没有回音的星海报名字，正好倒过来。地点在澄海（2026-10-28 读完 B 线返修版以后定）：白汀外泊外圈一段老泊环脱落，碎片进了澄海的天，连烧几夜。盛那时在一艘下行的海星兼航船上，这艘船也成了其中一颗，帆纹还亮着就往海里落。B 黎那时在澄海的一座偏岛上（她为什么在那儿，正篇往后写出来），朝它落下的方向跑过去，把人从水里拉出来。时机：B 线把澄海这一段写足以后、盛离开澄海以前。泊环为什么脱落，正篇再定。
2. **两个夜晚。** 盛想起来的那一刻，序011 望昼塔上那一夜和眼前的夜叠在一起，同一颗流星划过两个夜晚。定在砚泉照壁（2026-10-28 读完 A 线返修版以后定）：接舟季的夜里，修院钟楼顶上，彩窗的颜色一块块熄掉的时候。照壁是 A 线黎落脚的城，B 线让盛在同一座城里想起来。
3. **层落之夜。** 在永恒打破轮回的时候，神撑起来的那些层一层层落下来，下了一整夜的流星。星球没有毁，只是从此只剩一层天。盛在望昼塔上回头，看云海上的塔。序011 那位老人早说过：“哪天那些层要是掉下来，天上能下一整夜的流星。”

星海里本来就有普通的流星：碎石进到大气，星潮边上擦出的光（新）。写普通流星的时候，别让它每一回都有意义。

## 九、写法

1. 远行至少写清：为什么出发，实际坐哪条船，路上谁出力，到了谁来接，下一程靠什么（已有）。
2. 每次穿梭给一个身体上的感觉，写一两样就够，不讲原理。
3. 星海的大，靠时间和距离写：几周的航程，错过的窗口，到港时对方那边已经换了季。
4. 船窗外不是一片黑：有星潮的流光，远处恒星的颜色，近处港口的灯。
5. 不同的船不同的样子：镜舟不是星帆，砚泉的星舟也不是燧庭的样机（已有）。
6. 不让每一程都出事（已有）。
