## 先读这一段

旧流程需要较大范围重新检查，尤其是力量认识、跨卷动机、派系的主动行动和段落的幻想表现；六篇序卷、早重逢、两位主角的独立生活、实际学习与双向必要互助却仍有可保留的基础。

本案先以旧V01—V05作为坐标，把新构思放在可比较的位置。节点不是章节，也不等于必须各占同样篇幅；一张卡可以覆盖数场戏或一个中篇的关键转折。确定的是这段事情为什么发生、人物选择了什么、离场以后留下什么。章位、具体天数与总字数暂不重新分配。

本案里有实际冲突，也有一次公平落败、一段平安航程、一场成功的灯潮、一个认真选择的住处。新方向要在这些不同的经历里成立，不能把所有地方再写成同一套“信息有错—重新核验—获得认可”。

## 一、先把两条故事顺着讲通

### A的因果线

**接到求援 → 接受照护 → 见到同材异法 → 做一份自己的工作、寻找下一程 → X0本人重逢与正常告别 → 到砚泉真正学艺 → 松声院取得照夜 → 带着责任离山 → 春市从失去领灯到完成散灯潮 → 孟回舟旧源分别交付 → 在衡川做成水轮 → 已完成交付的人仍被神封留住 → X1真实互助与首次核心级神战 → 活人过河、伤者休养、地方继续。**

节点改变的不只是黎的装备。X0以前，她的希望仍含“能否再次相见”；X0以后，她知道本人相见已经发生，接下来的问题是共同生活、故乡现状和自己的当下选择。她不会每到一地又追逐一件假复活遗物。

### B的因果线

**本线正常工作 → 主动认识普通黎并问旧事 → 当下恋情成立 → 澄海分别完成工作与学习 → 先练有限施术 → 白嫁舟取得白誓 → 分清古咒再开与真正归岸 → 平安完成一次航程 → 家船婚礼与望归真实帮助 → 衡川住下、两份工作 → 盛继续发展自己想练成的攻防。**

A前段的强烈失去不要求B每次紧接着出事。B盛有受教育、被帮助的真实人生，对黎的喜欢也靠当下相处展开。普通B黎有知识与能力，同时失去神格；不得把她写成隐匿全能的终局人物。

### 阅读中的照应不等于因果传信

A看到一盏矿灯，B相邻一章也在用类似器物，可以形成认识对照；不表示两人处于同一天或听见对方的话。实际跨版本传递只通过有源本人访程及其携物、言谈发生。

X0来自B V14，X1来自B V17。读者在A较早看见成熟盛，B线随后写出她怎样练成；不是B V01／V05的盛因为另一个章节需要就突然觉醒。

### N-A01｜星帆把她接上去

**现场与位置：**A；旧V01／U01-1。  
**来源与状态：**沿用节点＋新表现。据`04#v01；v0.5末篇台账；新试案4.1`展开。

**场面与选择**

巡测支舟本来在外侧做航标观测，接收到短汀六的求援。领帆者乔映汀（新拟）带队靠近，舷外护息帷垂成一条发亮的窄廊，接人的手与安全索先到，身份询问留到人有力气说话以后。黎拒绝丢下盛交给她的记录器；医护把物件放在她能看见的位置，一同移交。她没有因看见异星帆船就忘记伤痛，也没有为了写更多绝望而再次被拒救。

**即时结果：**黎与真实物件抵达船内，获得治疗和临时住处；短汀六另行拖带或停置，去向明确。她的求援先产生结果。

**近期影响：**巡测船将她带到实际行程经过的转乘外站，N-A02、N-A03在恢复期发生；乔的工作不围绕黎改成永久护送。

**远段影响：**乔可以在后续航季再相遇，带来她自己新航线的变化。接人产生信任，不产生黎必须终身服从船队的债。

**感情与人物：**这是悲痛中第一次能够放心睡一会儿。暂时不安排主动求吻、立志弑神或立即恢复全部行动。

**谁知道了什么：**船员知道求援位置、艇况和黎自述；不知道B、盛的复活、全套永恒实验。黎最初只看见有人用陌生方法完成了救援。

**进入正文前的条件：**接收范围、航次与维生余量要在写作前核对。当前留档序080求援已发，不能重写成第一次发报。巡测支舟不直接改名为晚禾，不增加晚禾载客量。

**移除此节点会怎样：**没有本节点，黎的生存与外站立足无来路。

### N-A02｜同一块石头，另一种亮法

**现场与位置：**A；旧V01／U01-2。  
**来源与状态：**新增事件；承接矿石试案。据`新试案2、3、6.2；04#v01`展开。

**场面与选择**

康复到可以短时走动后，黎看乔为晚班换帆。矿石仍带着灰色矿皮，乔用呼吸、咒音与帆索把光引出去，外面的帆沿星潮张开。黎认得其中的材料，提出自己在永恒见过的用法。乔也问她房间怎样换成另一处庭院，双方各有不懂的地方。一次试用中，黎模仿发音却只让桌边的灯闪了一下，乔把灯收回去，说明这种练习不能拿来顶替正式领帆。

**即时结果：**黎见到一个不依赖永恒设施网络的真实用法，接受自己熟悉的解释仍有缺口。没有拿到新神核、通用施法能力或实验真相。

**远段影响：**为A观察不同神术与B/C的自然力量继续存在建立阅读基础；后续仍需另外证明神的具体施行。

**感情与人物：**乔的普通笑话使黎短暂想接话，随即又想起盛。一次发笑不撤销悲伤，也不需要旁白责备。

**谁知道了什么：**新增认识为“同材可异用”。“永恒的某项作用由一个神持续决定”仍未得到证明；颜色、鸣声和材料相似不是完整证据。 本轮不抹掉v0.7末篇已写的“永恒之神”称呼与遭遇；新的发现是对自然力量、技术用法与神的独立施行作更准确区分。

**进入正文前的条件：**星髓及材性仍是候选名。船上施法需已训练者、有效护息和器具；不把星海写成处处可裸身呼吸。

**移除此节点会怎样：**去掉以后，新幻想只剩换船外观，黎的认知变化会成为别人灌输的一段设定。

## 八、如何判断节点可以继续细化

先看单条A能否讲通，B是否也有独立愿望与完成；再看交错阅读是否产生新的理解。某节点的连接如果只是“这里又听说另一处有线索”，需要补人物关系或实际工作；如果每一场都在救一个无法离开的人，则需要改变其中一些故事的目标与高潮。

接下来可以逐个审读节点的画面、选择和影响，接受、改写或搁置某卡，不必立即推翻三十卷。只有节点变化确实牵动旧日历、访程、神器来源或终局条件时，再据影响表回写相应位置。

**本轮已完成节点设计，不等于这些故事已经写成正文，也不等于跨版本与复活机制全部通过。**
