# 叙述与句式检查

本页用于起草、精修与重写。P004、P009和作者当前要求优先；检查服务于人物、语言与阅读感受，不鉴定作者身份，不以词频、固定句长或检测分数判定文学质量。检查意见、命中清单与修改过程不进入小说正文。

最常见的几种毛病和每章的用词警戒线，先看[写作须知](../../创作/写作须知.md)。2026-10-28 的词频结果见[问题清单](../../参考归档/2026-11-14整理/过程记录/问题清单.md)：序卷里“慢慢”“一点”“轻轻”还明显偏多，正篇多“轻轻”“缓缓”；确认、核对、接收、交接这套冷词集中在第 5–6 篇是故意的，日常戏里少用。数字只是线索，判断仍按本页逐处做。

## 逐段检查的对象

| 类型 | 需要辨认的情形 | 处理与保留边界 |
|---|---|---|
| 成套对比与换壳 | “不是……而是……”“并非……而是……”“那不叫X，那叫Y”反复先否定再拔高 | 按P004重写整句；普通事实纠正仍可用，不把所有否定词禁掉。 |
| 作者安排露出 | 旁白解释为何不加危险、为何不立刻和好、为何不把物件写成线索 | 直接写场内发生的事。删掉对未采用写法的说明，不另补一句“没有说教”。 |
| 防错式否定 | 人物没有误会或行动意图，旁白却证明没有自动获得权限、没有把物件变出来、没有把今天变成永远 | 若是后台连续性约束，留在记录里；若确实改变人物眼前选择，则用她的判断、追问或受阻写清。 |
| 虚设极端作对比 | 先提出没人想到的卖艇、毁灭、突然大险，再宣告没有发生 | 检查场内是否有人真实期待或打算这样做。没有就去掉虚设前提。 |
| 伦理与心理代判 | 每次照顾都解释尊重，每次回忆都证明没有把眼前人当替身，人人准确分析自己的防御与边界 | 让人物的言行承担分量；重要冒犯与真实自省可以直接写，不强迫他们时时正确、时时能解释。 |
| 情绪重复说明 | 先命名情绪，再列动作，最后再讲一次情绪含义 | 保留有新信息的部分。直接说想念、喜欢、害怕可以很有力，不把所有心理删成手指和杯沿。 |
| 通用虚指 | “某种说不清的东西”“有什么在心里碎了”等脱离具体对象 | 有真实不确定、声音来源不可见时可保留；人物知道自己在意什么时，不以模糊词遮住。 |
| 身体反应轮换 | 眼睫、喉结、指尖、呼吸依次承担所有情绪，动作相同却没有现场触发 | 保留真实生理反应、身体吸引与具体动作；同一场和相邻场重复时调整，而非禁止身体描写。 |
| 现成比喻与强制景物 | 石子与涟漪、浮木、命运齿轮等替代当下景象；环境每次都恰好响应心情 | 看比喻是否来自此人的经验、是否有独特观察；不为去套式强行换一个更生僻的比喻。 |
| 章末道理与顿悟 | 每场都以“终于懂得”“真正的意义”“这就是……”总结 | 有具体误判被改变时保留认识；读者已经明白的含义不再讲解。章节可以自然休息，不必都用险情或金句结尾。 |
| 全员同声与对称对白 | 每人轮流完整陈述立场、回应过于标准，闲谈像论证或心理咨询 | 按人物的专业、欲望、疲倦、亲疏写语气。不要为显得自然故意塞口头禅、错别字或毫无理由的冲突。 |
| 账目式叙述 | 几夜床饭、哪次实收、权限边界和每个物件逐节重新清点 | 会改变选择、带来代价或承载感情的部分完整写；稳定的常规过程可简短过渡，精确账留接续记录。 |
| 同形的小成长 | 不同职业都走“旧理解出错—实物纠正—承认有限—交接—得到认可” | 区分不同本领与困难，让已经学会的部分熟练发挥。新场景有自己的结果，不每次再教同一道理。 |

“没有”“终于”“轻轻”“一点”“仿佛”本身不是错误。否定、长句、直接心理、专业解释、非对称对白和普通闲笔均可保留。不要用一种固定的短句模板替换另一种模板。

## 本项目的识别例

以下位置来自重写前原稿，仅用于辨认问题；对应源已备份到项目外，修订后以当前原文为准。

- 原056：“返程观察没有忽然变难来证明这是最后一次。”这在解释作者的编排。保留返航的实际动作即可，不让叙述者讨论怎样证明终场。
- 原030：“没有借着返程突然变成一条织好的围巾。”说明亮线收进袋里已能交代状态，不必否定无缘出现的成品。
- 原048：“她们没有在夜里重新给房间换一套家具。”可直接写挪书、挂外衣、整理床铺。
- 原049关于“不能由她一个人把艇卖掉”与付船费不会让故事“自动翻到下一页”的说明：人物并未想卖艇，也没有把付款当播放操作，优先删此类防错旁白。
- 原006“她的口味还不能从一顿饭就全看出来”、原020“没有用今晚已经亲过来打趣……”：回读前后，动作和对白足以表达时，不再代读者作判断。
- 原003“她终于明白，是瓜”：陌生语言造成的具体误认与笑处，保留。不能按“终于明白”命中机械删除。
- 原001对有限救援承诺的理解、原009旧图不是入口、原069余蘅限定引忆与所掌材料：当时人物确实在追问能否救人，边界有剧情用途，不能与无缘说明一起删掉。

## 实施顺序

1. 完整读场景，先辨人物当下想做什么、所知和动作因果，列出必须保护的有效对白、情绪、亲密与地方生活。
2. 用关键词检索定位可疑处，同时连续阅读相邻场景查结构重复。自动命中只产生候选，不能直接变成修改指令。
3. 逐处判断：这句回答了本场真实问题吗？增加了事实、声音、情绪或气氛吗？删后会不会让因果、视角或语气断裂？
4. 有问题才在完整语境中修改。能删掉附带说明就不硬写替代金句；需要补动作和心理时，补实际内容，不只换同义词。
5. 连读修订后的完整场景及前后接缝，检查语气、节奏与事实。更新受影响记录，原有台词不因检查清单而全部磨平。

检查清单只在创作前后使用。不得把本页的“不能自动……”“不要为了……”翻译成新的旁白，否则会重新制造同一问题。检查结果及逐条处理依据留在项目外工作材料，正文不夹说明。

## 参考与效力

[Reinhart等人的文体比较研究](https://arxiv.org/abs/2410.16107)研究了不同模型与人类文本在语法、词汇和修辞上的系统差异。它支持检查整体风格变化；本页不将其推广为某个中文词能证明AI作者。

[qu-ai-wei的中文编辑案例](https://github.com/LifelongLazyLearner/qu-ai-wei)提示将套路视为编辑线索、保护原有事实与声口；[小说表达案例集合](https://github.com/GlowingCake/awesome-ai-trace-killer/blob/main/README.md)提供身体套话、总结与同声对白的观察例。本项目只参考可核对的现象，不采用来源中的自动禁词、减字比例或形式配额，不安装任何工具。

[webnovel-handbook的编辑讨论](https://github.com/miserylee/webnovel-handbook/blob/main/docs/core-writing/06-ai-writing-guidelines.md)提示保护有辨识度的表达、检查过度总结与提示词扩写。其对固定冲突、章末钩子等建议不构成本项目要求。本文的防错旁白、账目重复与同形成长判断主要来自本项目原文核读。
