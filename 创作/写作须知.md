# 《她与神话》写作须知

2026-10-28

写新章之前先读一遍，写完照最后的清单自查。下面的规矩，来自序卷 80 章和正篇 48 章两轮润色里删改得最多的句子。

这份只讲别写成什么样。要写成什么样——全书的核心“爱世界”、两个人各自的声口、几条线怎么分——看[文风设计](文风设计.md)。

## 三条底线

1. **写动作，不写动作的意思。** 读者从动作里能看出来的，旁白不要再说一遍。
2. **写她做了什么，不写她没做什么。** “没做”本身是情节时才写。
3. **场景收在一个动作或一句台词上。** 不收在总结、领悟或“她想……也想……”上。

这三条管的是旁白替读者下结论，不管人物自己的念头。她心里真是这么想的，就直接写，比如“她想盛了”，一句就够，后面别再补一句这说明了什么。长句也照用，读着顺就行。

## 常见毛病

前六种最常见，先盯住它们。

| 毛病 | 长什么样 | 怎么写 |
| --- | --- | --- |
| 动作后的解释句 | 动作写完，再补一句“这让……”“她知道……也知道……” | 删掉解释，动作留下 |
| 领悟句、总结句 | “她本来以为……如今……反而……”“她终于明白……”“她第一次觉得……” | 换成她接下来做的事，或者直接删 |
| 否定框架 | “她没有……，只是／先……” | 直接写她做的那件事 |
| 欲言又止 | “很想问……，话到嘴边，又先……” | 要么让她问出口，要么只写她手上干了什么 |
| 副词垫底 | 慢慢、终于、轻轻、认真、一点、随后，每个动作都修饰一遍 | 删，或换成更具体的动作 |
| 程序词 | 确认、核对、实际、真正、具体、来源、范围，逛街吃饭也像工作记录 | 换成看、比、翻、对；日常戏里一个不留 |
| 礼貌程序 | 拍照先征询、离开先报备、吵完当场分条复盘 | 删；“同不同意”本身是冲突时才写 |
| 书面虚词 | 便、仍、随后、此刻、如今，对白后用“答” | 叙述用就、还、接着、现在，对白后用“说” |
| 抽象比喻 | “像把这几个字郑重放到两个人之间”，比喻落在概念上 | 只用落在人物眼前那颗星具体东西上的比喻：永恒的接合、云海、光桥，澄海的帆和缆 |
| 转述代替对白 | “她说得很认真。……”接一大段间接引语 | 关键的话让人物自己说出来 |
| 对白太规矩 | 一句塞三层意思；复述对方原话；“我知道”“嗯”收尾 | 一句一个意思；允许打断、说半句、答非所问 |
| 设定讲解 | 解释一样东西怎么运转 | 名词直接用，写人怎么用它、嫌它什么 |
| 压缩断句 | 前后缺衔接、重复句、漏句 | 写完通读一遍，读不顺的地方补上 |
| 矫枉过正 | 为了躲开上面这些，整章切成一行一段的短句，念头和长句全删光 | 长短句换着用；人物真有的念头照写 |

## 用词警戒线

按每章算。数字不是配额，也不用来判定好坏：超了就回头挨个看一遍，能删的删，留下的要说得出为什么留。用不到就别用。

| 词 | 日常章 | 工作章 | 超了怎么换 |
| --- | --- | --- | --- |
| 确认／核对／实际／真正／具体／来源 | 0 | 3 | 写动作：看、比、翻、对 |
| 没有……只／先 | 1 | 1 | 改成正面叙述 |
| 话到嘴边／很想问……却先 | 0 | 0 | 问出口，或只写手上的动作 |
| 慢慢／轻轻／微微 | 3 | 3 | 删，或换更具体的动作 |
| 一点（修饰感受） | 5 | 5 | 删，或给出具体的量 |
| 终于／随后 | 2 | 2 | 删，靠分段换气 |
| 认真／郑重／认认真真 | 2 | 2 | 用动作表现 |
| 像……／仿佛 | 2 | 2 | 只留落在具体东西上的 |
| 便／仍（叙述里） | 2 | 2 | 换成就、还 |

序卷第 5–6 篇的程序词是故意放开的，节奏安排见[文风规范](文风规范.md)。

## 改写示例

八组都出自正篇原稿，括号里是章号。

| 毛病 | 原句 | 改句 |
| --- | --- | --- |
| 解释句（025） | 问出口时，她仍有一点难为情，却没有再绕开自己的需要。 | 问出口的时候，她脸上还是有点热。 |
| 总结句（019） | 原先一直逼着她往前赶的念头，此刻终于落到一个具体的早晨。明日她知道要去哪里…… | 明天早上要去哪儿，她知道了。 |
| 否定框架（024） | 这一次，她没有急着把所有词都找齐，先记住帆从松到紧的样子。 | 这回她不去找词了，只记住帆从松到紧的样子。 |
| 欲言又止（034） | 陶本来还想讲下一次能会面的港口，话到嘴边，又先抱紧了一点。 | 陶令仪本来还想说说下回能在哪个港口碰面。她把人抱紧了一点。 |
| 抽象比喻（029） | 周荞却一直盯着他们的手，仿佛那道接缝若没有被当场指出来，就会重新被许多别的话盖过去。 | 周荞的眼睛却一直钉在他们的手上。 |
| 转述代替对白（018） | 她说得很认真。知更带她走过了最初的长航，她开始能守住自己那一小片位置…… | “想留一阵。”盛放下筷子，“我在知更上跑完了第一趟长航，自己那一小块能守住了。” |
| 书面虚词（019） | 她答是，随即从记录器里调出方裴的署名。 | 她说是，接着从记录器里调出方裴的署名。 |
| 结尾带总结（015） | 黎答好，将词簿放到枕边，第一次认真看了看这间要再住几夜的小屋。 | 黎说好，把词簿放到枕头边上，抬头看了看这间还要再住几晚的小屋。 |

第一组最典型：“没有再绕开自己的需要”是替读者下结论，换成脸上发热，读者自己就看懂了。序卷的五组示例也在[文风规范](文风规范.md)。

## 章名

作者 2026-10-28：“目前的章节命名有点尴尬。”以前的章名多半是半句话（“她想问的那些事”“那天下午有一点长”），读着像一句总结；序卷 80 个里有 19 个带“她”，可两个女主都是“她”，目录里分不清说的是谁。

- 两到五个字为主，最长不过七个字。
- 落在一样看得见的东西上：地方（望昼塔、南堤小舍）、物件（垫片、折信页）、人（方苇、盛世澜）、时刻（05:26:18、出航日）。
- 写谁的那一章就用谁的名字，不用“她”。
- 不写成心情、总结或半句话；不用“……的时候”“把……”“一点”“那天……”。
- 不剧透这一章的转折。
- 目录连起来读，要看得出是在哪儿：永恒的章名带叠层的东西（接合、选层屏、层轮），船上带船上的东西，澄海带帆和港，砚泉带钟楼和彩窗。
- 同一个词在目录里别出现三回以上。
- 编号和锚点不跟着改（序001、`#ch001`），改名只改标题。

序卷改名前后的对照在[正文导航](正文导航.md)。

## 写完自查

每章交稿前过一遍：

- [ ] 每个动作后面，有没有一句替读者解释它的意思？
- [ ] 有没有“她本来以为……”“她终于明白……”这样的领悟句？
- [ ] “没有……只／先”和“话到嘴边”超了吗？
- [ ] 日常戏里还有确认、核对、实际、真正吗？
- [ ] 慢慢、终于、认真、像……超过警戒线的，挨个看过了吗？
- [ ] 对白念出声顺不顺？像不像这个人会说的话？
- [ ] 这一节有没有跑进另一个人的心里？
- [ ] 每个场景收在动作或台词上了吗？
- [ ] 通读一遍：有没有重复句、漏句、接不上的地方？是不是切得太碎了？
- [ ] 章名短吗？落在一样东西、一个地方、一个人或一个时刻上了吗？
