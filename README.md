# 《她与神话》设定包

2026-11-25 整理。作者想重新创作这部小说，所以这里只放设定、作者定下的方向和两份写法说明，不放正文：序卷、正篇、番外、行旅、寓言都没有放进来。

线上仓库：https://github.com/xi-kari/her-and-myth-settings 。每个文件都能用文末清单里的原始文本链接直接读取，不用登录。

## 用之前要知道

1. **有几处内容来自旧正文**，可以参考，不必照着写：
   - `创作/写作须知.md` 的「改写示例」，`创作/文风设计.md` 的「人物声口」表和「校准片段」，引了旧正文的原句和几小段原文，用来对照声音和分寸。
   - `设定/补充设定.md` 的「正篇地方事实」一节、`设定/角色补充.md` 的「正篇已写事实」一节，是旧稿正篇 065—232 写出来的事实。两份文件前面「2026-10-28 补充」那部分是设定本身。
   - `作者当前要求.md` 开头的「当前资料依据」「现行进度」和最后两节（续写 065—232、065—232 的润色与收尾判断），讲的是旧稿写到哪、怎么续写和润色。中间各节是作者对故事、世界和文风的要求。
   - `作品核心.md` 的「现行文本」一节，`设定/写作规则/持续创作与交接.md`、`设定/写作规则/正文修订与重写安排.md`，讲的也是旧稿的进度。
   - 设定和写法里常用旧稿的章节号指具体场面，比如序078（出航日）、序080（星外）、正篇032。这些原文都不在这里。
2. **有些链接打不开**。部分文件链到 `正文/`、`参考归档/`，或者 `创作/` 里的其他文件（《文风规范》《表达与文风》《正文导航》等），这些都没有放进来。`设定/讨论方案/` 里的《书册与外篇设计》《本人复活与首册重逢接口》只是说明页，完整原文在作者项目的参考归档里，也没有放进来。
3. 00—05 原文里混着作者方向、工作方案、历史残句和没定的问题，哪些算数看《来源与效力》。
4. 01 号文件有 1.4 MB，GitHub 网页上可能显示不全，读它用原始文本链接。

## 建议的阅读顺序

1. 作品核心
2. 作者当前要求
3. 设定总览、来源与效力、待定与冲突
4. `设定/世界/` 三份
5. 动笔前读 `创作/写作须知.md`、`创作/文风设计.md`
6. 写到哪颗星、用到什么机制，再去查 00—05 原文
