每章一个文件，文件名是“章号_章名.md”。

## 怎么读

先读序卷，再选一种读法：

- **单读一条线：** 序卷读完，接着读 `A线/` 或 `B线/`，照章号往下。每条线自己成一本书，单读能完全看懂。
- **两条线合读：** 序卷读完，按 A001、B001、A002、B002……一章一章穿插。同号的 A 章和 B 章是一对，每一卷两边章数相等。

`AB配对表.md` 列出每一对同号章，`AB关联.md` 记两条线之间暗暗相连的地方（同一句话、同一个物件、同一刻）。想自己先读出来，可以读完再看。
